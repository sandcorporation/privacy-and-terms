줄기노트 개인정보처리방침

게시일 2026년 8월 14일

앱이 만든 기록은 사용자의 기기 안에만 있고, 사용자가 대화하는 상대(OpenAI)에게는 사용자 본인의 API 키로 직접 전달됩니다. 개발자는 사용자의 대화도, 음성도, API 키도 받지 않으며 볼 수 없습니다.

예외는 하나, 신고입니다. 사용자가 비서의 말을 신고하면 그 내용이 개발자에게 전송됩니다. 사용자가 직접 누를 때만 일어나고, 보내기 전에 무엇이 나가는지 화면에 그대로 보여줍니다(5번).

1. 이 앱이 어떻게 동작하는지

줄기노트는 사용자가 직접 발급받은 OpenAI API 키를 등록해서 씁니다. 앱은 그 키로 사용자의 기기에서 OpenAI 서버(api.openai.com)에 직접 요청합니다. 그 사이에 개발자가 운영하는 서버는 없습니다.

2. 개발자가 수집하는 정보

없습니다.

사용자가 신고를 보내는 경우를 빼면 사용자의 기기에서 개발자에게 전송되는 데이터가 없습니다(5번). 앱이 스스로 무언가를 개발자에게 보내는 일은 없습니다.

분석 도구(애널리틱스), 광고 SDK, 크래시 리포팅을 넣지 않았습니다. 사용자를 식별하는 값 — 기기 ID, 설치 ID, 계정 — 을 만들지도, 저장하지도, 전송하지도 않습니다.

3. 기기 안에 저장되는 정보

아래는 모두 사용자의 기기 안에만 저장되며 밖으로 전송되지 않습니다.

저장되는 것어디에
대화 기록(말한 것의 전사와 글로 쓴 것)앱 전용 저장소의 데이터베이스
대화에서 정리한 지식(이름·설명·이음·출처)같은 데이터베이스
오래된 대화를 눌러 담은 압축본과 그 자국같은 데이터베이스
앱이 써 준 초고같은 데이터베이스
프로젝트 제목·목소리·색·추가 지시문같은 데이터베이스
앱 설정(말하는 방식, 기억 범위 등)앱 전용 설정 파일
OpenAI API 키앱 전용 설정 파일에 암호화해서 (6번 참고)

앱을 삭제하면 위 데이터는 기기에서 함께 사라집니다. 앱 안에서 프로젝트를 지우면 그 프로젝트의 대화·지식·압축본·초고가 함께 지워집니다.

4. 제3자(OpenAI)에게 전달되는 정보

사용자가 비서와 대화하려면 그 내용이 OpenAI 에 전달되어야 합니다. 전달되는 것은 다음과 같습니다.

  • 마이크로 말한 소리 — 마이크 버튼을 누르고 있는 동안, 또는 통화를 여는 동안 녹음된 오디오가 OpenAI Realtime API 로 전송됩니다.
  • 글로 쓴 메시지와 최근 대화 기록 — 비서가 맥락을 알도록 최근 대화 일부가 함께 전송됩니다. 얼마나 보낼지는 설정의 "기억" 에서 사용자가 정합니다.
  • 정리·압축·초고에 쓰이는 대화 구간과 지식 — 사용자가 "정리하기" 를 누르거나 초고를 요청할 때, 그리고 오래된 대화가 자동으로 눌러 담길 때 해당 내용이 전송됩니다.
  • 소리로 답하기가 켜져 있을 때의 비서 답변 텍스트 — 음성 합성을 위해 전송됩니다.

전송은 모두 사용자의 API 키로 이루어지므로, OpenAI 에서 이 데이터는 사용자 본인의 계정에 속합니다. OpenAI 가 이 데이터를 어떻게 다루는지는 OpenAI 의 정책을 따릅니다.

  • OpenAI 개인정보처리방침
  • OpenAI API 데이터 이용 정책

전송에 쓰이는 주소는 api.openai.com 뿐입니다 (/v1/realtime/*, /v1/chat/completions, /v1/audio/speech).

5. 신고를 보낼 때 (개발자에게 전송되는 유일한 경우)

비서가 만든 말·카드·초고·정리된 노드가 불쾌하거나 잘못됐을 때, 그 자리에서 신고할 수 있습니다. 신고는 사용자가 직접 누를 때만 전송되며, 앱이 스스로 보내는 일은 없습니다.

전송되는 것은 다음 다섯 가지가 전부입니다.

나가는 것예
신고된 글비서가 한 말 그대로
그것이 무엇인지말·카드·초고·노드 중 하나
사용자가 적은 사유비워 두어도 됩니다
앱 버전1.0 (1)
보낸 시각

전송되지 않는 것: 프로젝트 제목, 추가 지시문, 신고한 것 말고 다른 대화, 압축본, OpenAI API 키. 그리고 누가 보냈는지 알 수 있는 값을 함께 보내지 않습니다 — 기기 ID나 설치 ID 같은 식별자를 만들지 않으므로, 같은 사람이 두 번 신고했는지 개발자는 알 수 없습니다.

보내기를 누르기 전에 위 내용이 화면에 그대로 표시됩니다. 요약하거나 줄이지 않습니다.

받는 곳은 개발자가 운영하는 자동화 서버(n8n)이며, 신고 내용은 앱의 문제를 고치는 데에만 쓰입니다.

6. API 키를 어떻게 보관하는지

등록한 OpenAI API 키는 평문으로 저장되지 않습니다. Android 키 저장소(Android Keystore)가 쥐고 있는 마스터 키로 암호화(Tink AEAD)한 뒤 그 암호문만 앱 전용 파일에 남깁니다. 마스터 키는 기기 밖으로 나갈 수 없습니다.

키는 OpenAI 서버로의 API 호출에만 쓰이며, 그 외 어디로도 전송되지 않습니다. 설정 → OpenAI API Key 화면에서 언제든 지울 수 있습니다.

7. 권한

권한왜 필요한지
마이크소리로 대화할 때만 씁니다. 항상 듣고 있지 않습니다 — 마이크 버튼을 누르거나 통화를 시작해야 열리고, 손을 떼거나 통화를 끝내면 닫힙니다. 앱을 켤 때는 묻지 않습니다 — 처음 말을 걸려고 할 때 안내를 먼저 보여드리고, 동의하셔야 권한을 요청합니다. 허용하지 않아도 글로는 그대로 대화할 수 있습니다.
인터넷OpenAI API 호출.
오디오 설정소리가 나가는 곳(스피커·수화부·이어폰)을 바꾸기 위해.
블루투스연결된 블루투스 기기의 이름을 화면에 보여주기 위해서만 씁니다. 거절해도 소리는 정상적으로 나갑니다.

8. 아동

이 앱은 만 14세 미만을 대상으로 하지 않으며, 아동으로부터 어떤 정보도 수집하지 않습니다.

9. 자동 백업

Android 의 자동 백업이 켜져 있으면 앱의 설정 파일이 사용자 본인의 Google 계정으로 백업될 수 있습니다. 암호화된 API 키가 그 파일에 들어 있으나, 복호화에 필요한 마스터 키는 기기를 벗어나지 않으므로 다른 기기에서 복원해도 키는 읽히지 않습니다 — 새 기기에서는 API 키를 다시 등록해야 합니다.
